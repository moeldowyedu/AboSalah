# Mohammed Salah Eldowy — abosalah.com

Personal site of **Mohammed Salah Eldowy** — Founder & CEO, False Negative Integrated Solutions & Scorit.

Static single-page site. No build step.

## Stack

- Bootstrap 5.3 (CDN) for grid + navbar collapse
- Font Awesome 6.5 (CDN) for icons
- Space Grotesk / Inter / JetBrains Mono (Google Fonts)
- `assets/css/styles.css` — brand tokens + components
- `assets/js/script.js` — loader, role rotator, scroll reveal, theme toggle

## Brand tokens

| Token | Dark | Light |
| --- | --- | --- |
| `--brand` | `#5b8cff` | `#2f5fe0` |
| `--signal` | `#55e6c1` | `#0f9e86` |
| `--ink-900` | `#05070b` | `#ffffff` |
